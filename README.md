# NorSignal

Branchespecifik cyber threat intelligence for nordiske virksomheder.

Dette projekt indeholder to dele:
1. **Hjemmeside (`/website`)**: Marketing- og produktside med trusselsbillede, priser og booking.
2. **App-prototype (`/app`)**: Interaktiv prototype af kundeappen i en smartphone-ramme.

## Sådan køres projektet

### Mulighed 1: Med Node.js (anbefalet)
Kør den indbyggede webserver:
```bash
node server.js
```
Åbn derefter i din browser:
- Hovedportal: [http://localhost:3000/index.html](http://localhost:3000/index.html)
- Hjemmeside: [http://localhost:3000/website/index.html](http://localhost:3000/website/index.html)
- App-prototype: [http://localhost:3000/app/index.html](http://localhost:3000/app/index.html)

### Mulighed 2: Direkte i browseren
Du kan også blot åbne `index.html` direkte i enhver moderne browser.
